## 东京三条线，本质区别是三张不同的路由表

DMIT 在东京用的是 Equinix TY8 机房，机器都是 KVM 虚拟化、AMD EPYC 7003（Milan）平台配 NVMe SSD，默认给 1 个 IPv4 加 1 组 /64 IPv6。硬件这三条线是一样的，拉开差距的是回程路由。

- **Premium（TYO.AS3.Pro）**：回程走电信 CN2 GIA，联通走 AS9929 / AS10099 精品网，移动走 CMI，去程也做过优化。1Gbps 端口。这是东京的旗舰线，也是国内访问体验最稳的一条。
- **Eyeball（TYO.AS3.EB）**：三网强制 CMI 回程，电信联通去程走 CTG GIA。对移动宽带更友好，端口最高能到 4Gbps。**这条线目前官网已查不到，多个来源都提到它处在下架或缺货状态**，别把预算押在它身上。
- **Tier 1（TYO.AS3.T1）**：纯国际互联，电信联通双程走 NTT，部分路径绕美走 Lumen，移动走 CMI。不针对中国大陆优化。端口 4–10Gbps。

一个容易搞混的细节：**Pro 系列流量用超是暂停服务，T1 系列是限速继续跑**。T1.WEE 超量后限到 50Mbps 但不停机，T1.MINI 及以上是 100–200Mbps 不限量。如果你有跑流量、挂下载、做中转的需求，这条规则比价格更值得先确认。

另外，不同测评给出的延迟区间不完全一致，综合看：东京走优化线路到国内的 ping 大致在 50–90ms，华东地区能压到 30ms 出头；T1 线路因为电信去程绕行，实测平均延迟会到 200ms 上下——联通和移动用户体感会明显好于电信用户。

## 下单前该想清楚的几件事

**库存是最不稳定的变量。** 东京 Pro 常年处于紧张状态，几轮补货都是因为回收了一批可用 IP 才短暂上架，官方也多次表示短期内不会大规模补货。看到想买的档位有货，犹豫的成本可能比省几美元更高。

**换 IP 政策相对友好。** 有来源提到 IP 被墙时每 15 天可免费更换一次，其余情况每次 5 美元。注意这个权益和部分促销码是互斥的——某些年付五折码明确要求 IP 更换限制为每 30 天一次并收费，折扣和灵活度得二选一。

**退款窗口很短。** 有测评站点整理的规则是：新购服务 3 天内、且流量使用不超过 30GB，可申请全额退款；30 天内可按剩余价值申请部分退款，需符合退款条款。想试线路的话，别一开通就先跑几天流量。

**超量策略是先看的，不是后看的。** Pro 超量暂停，T1 限速不停机。做网站和做下载站的用户，这一条会直接影响你选哪条线。

## 常见问题

**东京和香港该选哪个？**
香港延迟最低（大致 20–50ms 区间），但价格也最高，HKG Pro 入门款月付约 $39.9；东京 Pro 从 $21.9 起，延迟略高一点，性价比更平衡。核心业务、预算充足选香港，需要兼顾日本 IP 或亚太业务选东京。

**T1 便宜这么多，能替代 Pro 吗？**
看用途。T1 没有中国大陆方向优化，电信用户延迟会明显高；如果你只做东南亚业务落地、国际建站、备份或中转，T1 完全够用，还多了一个"超量不断网"的优点。但如果你在意国内用户的访问体感，别省这笔钱。

**Pro.TINY 只有 500GB 流量，够用吗？**
个人建站、轻量 API、远程开发够用。跑图床、视频、下载站不够。超量会暂停服务，不是降速，这点比"流量不够"更麻烦。

**东京机房现在的定位是？**
比香港便宜、比洛杉矶延迟低，是需要日本原生 IP 的同时又要保证大陆访问速度时，目前可选方案里比较扎实的一档。
